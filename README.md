### 👨‍💻 About Me

I am a **Frontend Engineer** and **Computer Science Student at Shahid Beheshti University (SBU)**. My primary engineering focus revolves around crafting large-scale enterprise modules, highly interactive web applications, and resilient modular systems.

- 🏗️ **Enterprise Engineering:** Developing core modules at **AsaanTech** for a large-scale **ERP System** (Dynamic Schema Form Builders, Drag-and-Drop Workflow Engines, and Financial Accounting Modules).
- 🔬 **Engine & Tooling Exploration:** Built complex React Flow graph builders, Tiptap-based custom block editors, high-performance virtualization tables, and interactive spatial map services.
- 📐 **Architectural Rigor:** Strictly applying **Feature-Sliced Design (FSD)**, **Clean Architecture**, **SOLID Principles**, and Design Patterns for maximum maintainability.
- 🧠 **Deep Computer Science:** Deep-diving into V8 JS Runtime Engine internals (*You Don't Know JS*), while preparing for foundational AI/ML and Solidity Smart Contract engineering.
